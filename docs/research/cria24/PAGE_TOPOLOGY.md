# Cria24 Page Topology

Target URL: `https://cria24.com/`

## Global Layout
- Long one-page React/Next landing page.
- Light warm background palette: `#F7F7F3`, `#F7F6F3`, `#F5F2EE`.
- Fonts observed: `Sora` for display/section numbers, `Inter` for body copy.
- No sticky header or fixed navigation.

## Sections
1. **Hero**
- Large faint `CRIA24`/`C24` background typography.
- Centered headline, stats row, desktop framed screenshot, mobile video mockup.
- Interaction model: static/time-driven video on mobile.

2. **Como Funciona**
- Numbered section heading and three process cards.
- Static cards.

3. **Portfólio**
- Stacked project cards with real portfolio images.
- Interaction model: click-driven "Próximo case" button.

4. **Quem Entrega**
- Lucas Vitale profile image, biography, and bullet list.
- Static.

5. **Depoimentos**
- Testimonial cards with avatar images and stars.
- Static grid with fade/mask feel.

6. **O Que Está Incluso**
- Six value cards and total market-price comparison.
- Static.

7. **Investimento**
- Express and Premium plan cards.
- Static CTA buttons.

8. **Garantia**
- Two guarantee cards.
- Static.

9. **FAQ / Final CTA / Footer**
- Accordion FAQ, dark image CTA card, footer with Instagram link.
- Interaction model: click-driven FAQ expansion.
